# Marae Engine website

This is a static HTML, CSS, and JavaScript site. It has no build step, package manager, analytics, or external font dependency.

## Edit

- `index.html` contains the page structure and public product information.
- `css/site.css` contains the responsive visual design.
- `js/site.js` contains the accessible mobile navigation behavior.
- `assets/` contains the Marae brand images used by the page.

Keep release and platform claims aligned with the current repository and published GitHub Releases. The source ZIP is not a prebuilt Windows installer.

## Publish

The `Publish Marae Engine website` GitHub Actions workflow deploys the contents of this directory to GitHub Pages when changes are pushed to `main`. The repository's Pages deployment source must be set to GitHub Actions.
